# 浏览器扩展：图片反推与收藏

本目录是 Chrome / Edge 的 Manifest V3 扩展。它通过本机提示词库调用已配置的视觉模型，并非独立模型或在线服务。

## 安装

1. 启动项目根目录下的本机提示词库，确认 `http://127.0.0.1:5178` 可以访问。
2. 在提示词库「设置」中填写 OpenAI 兼容接口、API Key 和支持视觉输入的模型。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
4. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择这个 `extension/` 文件夹。安装前已打开的网页可以刷新一次。

## 用网页图片生成提示词

1. 在普通网页点击扩展图标，选择「在当前网页打开收藏面板」；或右键图片，选择「把这张图片加入提示词库」。
2. 在面板中点选图片或粘贴图片链接，点击「AI 反推」。
3. 等待模型返回，检查、修改结果，再点击「加入提示词库」保存。

模型分析会消耗服务商额度；图片会发送到所配置的模型服务商。所选图片必须能被本机服务获取，受网站限制的图片可能失败。视频可通过同一面板处理，但需安装 `ffmpeg`，且部分网页视频可能只能使用封面分析。

扩展默认连接 `http://127.0.0.1:5178`，可在扩展弹窗修改本机地址。浏览器商店页面、浏览器内部页面等可能禁止扩展执行。快捷键默认为 `Alt+Shift+Y`。
