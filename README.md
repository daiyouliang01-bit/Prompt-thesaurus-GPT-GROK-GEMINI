# 提示词库 · 图片与视频提示词工作台

在自己的电脑上收集、整理和生成 AI 提示词。可以输入创作需求，也可以给视觉模型一张参考图片，让它分析画面并写出便于复现的提示词。仓库还包含浏览器扩展，可在浏览网页时选择图片并使用「AI 反推」。

> 图片反推是根据可见内容**推测**提示词，不保证找回原作者使用的原始提示词。

## 功能

- **提示词库**：添加、搜索、收藏和管理自己的提示词与图片、视频链接。
- **智能生成**：输入创作需求，可附参考图片，调用配置的模型生成提示词。
- **图片反推**：上传图片或提供图片链接，生成画面描述和提示词；结果可编辑后保存。
- **视频反推**：对视频抽帧后分析；需要本机安装 `ffmpeg` 和支持图片输入的模型。
- **浏览器扩展**：在网页中选取图片、视频或文字，调用本机服务反推或收藏。详见 [扩展安装与使用](extension/README.md)。
- **Google 云盘媒体同步**：由使用者自行配置和授权，供本机库同步图片和视频；提示词及案例记录保存在本机数据库中。

## 准备与启动

需要 **Node.js 22.13 或以上版本**。本项目运行不需要额外安装 npm 依赖；视频分析还需要 `ffmpeg`。

1. 克隆仓库并进入目录：

   ```bash
   git clone https://github.com/daiyouliang01-bit/Prompt-thesaurus-GPT-GROK-GEMINI.git
   cd Prompt-thesaurus-GPT-GROK-GEMINI
   ```

2. macOS / Linux 运行：

   ```bash
   ./start.sh
   ```

   或手动初始化并启动（也适用于已安装 Node.js 的 Windows）：

   ```bash
   npm run import
   npm start
   ```

3. 打开 [http://127.0.0.1:5178](http://127.0.0.1:5178)。首次启动会建立本机数据库，关闭终端会停止服务。

## 配置模型

打开提示词库的「设置」，填写服务商的 OpenAI 兼容接口地址、API Key 和模型名称。图片分析需要选择**支持图片输入**的模型；请按服务商说明填写接口和模型。生成及反推会向该服务商发送所选文本、图片或视频帧，并可能消耗其额度。

在网页的「智能扩写/反推」区域选择图片或视频，填写需要的目标模型或补充要求，再开始分析。图片反推不能保证精确还原来源，也可能遗漏细节，建议对照原图检查结果。

## 安装浏览器扩展

1. 确保本地提示词库已经启动，并在「设置」中配置视觉模型。
2. 在 Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」，选中本仓库的 `extension` 文件夹。
4. 在普通网页上打开「提示词库一键收藏」扩展面板，点选图片后选择「AI 反推」；生成后可检查并保存到本机库。

也可以在图片上点击右键选择「把这张图片加入提示词库」。浏览器内置页面和部分受限制的网页可能不允许扩展运行。扩展依赖本机服务，并不是独立的在线反推工具；网页图片以链接传给本机服务，能否访问取决于来源网站。

## 数据与隐私

公开仓库默认以**空库**启动，不包含原有私人数据库、云盘凭据、第三方案例、图片或模板。模型配置和收藏保存在本机 `data/` 目录；请勿把该目录或 API Key 提交到公开仓库。云盘同步需用户自行授权；云盘中是否有完整案例数据库取决于用户自己的备份。

一键下载案例数据包尚未提供。用户可以自行添加有权使用的内容。

## 项目结构

| 路径 | 作用 |
| --- | --- |
| `server.mjs` / `lib/` | 本机 HTTP 服务、数据库、模型调用和图片/视频反推 |
| `public/` | 提示词库网页 |
| `extension/` | Chrome / Edge 浏览器扩展 |
| `scripts/` / `seed/` | 初始化与数据处理工具；公开版不携带原案例库 |
| `data/` | 运行时本地数据库和媒体，不纳入 Git |
| `tests/` | 自动化测试 |
