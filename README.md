# 提示词库

本机提示词管理工具，支持收藏、检索、参考图片生成提示词，以及图片和视频反推提示词。使用自己的 OpenAI 兼容模型接口；视频反推需要 ffmpeg。模型可用性取决于所选服务商。

## 运行

需要 Node.js 22.13 或以上。在项目目录运行：

```sh
./start.sh
```

打开 http://127.0.0.1:5178，在设置中配置支持视觉输入的模型和 API 密钥。数据与设置保存在本机 `data/` 目录，该目录不会上传到仓库。

公开版首次启动为空库，不包含本机私人数据、第三方案例、图片或原模板；可自行添加内容。生成和反推会调用所配置的外部模型服务，图片会发送给该服务商。

运行测试：`npm test`。代码按 Apache License 2.0 提供，第三方内容仍适用其各自许可。
